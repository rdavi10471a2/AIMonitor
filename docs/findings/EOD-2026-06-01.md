# EOD Restart Notes - 2026-06-01

## Current State

- WinForms `AIMonitor.App` was stopped at EOD.
- The Monitor Status tab is now the default startup tab.
- The WinForms app owns the live MCP proxy hub; live tool calls should be visible in Monitor Status.
- The old bridge project has been renamed/reframed as `AIMonitor.McpStdioBridge`. It is a dumb stdio-to-WinForms-proxy transport, not workflow state.
- Workflow session identity is explicit and separate from transport identity:
  - `Workflow Session` is the edit/workflow scope and should be shared across files in one multi-file edit.
  - `Transport Session` is the MCP bridge/proxy connection lifetime and may be long-running.
- Blank session-completed rows should no longer steal selection from the last meaningful response payload.
